# Anjuman Sharear — Portfolio

Personal portfolio of **Anjuman Sharear**, UI/UX designer based in Dhaka.

- Selected work: Go Foods, SoulSound, and the live **Zentra** crypto dashboard
- Gallery of Dribbble and Behance shots
- Experience, services, FAQ and contact

## Built with

- Plain HTML, CSS and JavaScript in a single `index.html`
- [GSAP](https://gsap.com) + ScrollTrigger for scroll motion, [Lenis](https://lenis.darkroom.engineering) for smooth scrolling
- A canvas "dot face": a halftone portrait that splashes apart on scroll and regathers in the footer (`images/me.webp`)
- Palette: Eerie Black `#1A1A1A`, Rosso Corsa `#D60407`, White `#FFFFFF`
- Type: Bricolage Grotesque, Manrope, JetBrains Mono

## Run locally

No build step. Serve the folder and open it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

Works as-is on Vercel, Netlify or GitHub Pages (static site, root directory).
